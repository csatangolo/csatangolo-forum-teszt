# Éles előadókezelő – rendezvényválasztó és automatikus átvétel

## Javítások
- Ha nincs aktív rendezvény, automatikusan kiválasztja az első rendezvényt.
- Ha nincs rendezvény, létrehoz egy alap Fórum rendezvényt.
- A fejlécben megjelenik a rendezvényválasztó.
- A régi `speakers` tábla előadóit automatikusan átemeli az új `people` + `event_speakers` rendszerbe.
- Ezután a meglévő előadók szerkeszthetők lesznek az új Előadókezelőben.
