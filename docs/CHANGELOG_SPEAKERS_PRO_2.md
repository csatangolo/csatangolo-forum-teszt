# Előadókezelő PRO 2

## Újítás
- Előadói képfeltöltés közvetlenül a Managerből
- Feltöltés a Supabase Storage `forum-assets` bucketbe
- Feltöltés után automatikusan bekerül a kép URL-je az előadó adatlapjára
- Mentés után a kép a nyilvános oldalon is használható

## SQL
Nem kell új SQL, ha a Storage jogosultság SQL már lefutott.
